# QUẢN LÝ CÔNG TRƯỜNG XÂY DỰNG - NTCONS

Ứng dụng web quản lý toàn diện tình hình thi công, an toàn lao động, tiến độ, nhật ký ca và KPI thi đua tổ đội trên công trường xây dựng.

## Demo

- **Live**: https://quanlycongtruongntcons.vercel.app
- **GitHub**: https://github.com/trixd2026-max/quanlycongtruongntcons

## Công nghệ

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- React Router, Recharts, date-fns, Lucide Icons
- Chế độ Demo (localStorage) — sẵn sàng kết nối Firebase

## Chạy local

```bash
npm install
npm run dev
```

## Tính năng

1. Tổng quan tháng (Dashboard)
2. Nhập KPI & Nhật ký tuần
3. Thi đua tổ đội
4. Vi phạm an toàn & Kỷ luật
5. Theo dõi tiến độ & Chất lượng
6. Nhật ký ca & Phân công
7. Quản lý công nhân
8. Cài đặt công trường

## Phân quyền Demo

Sử dụng panel bên trái để chuyển vai trò:
- Chỉ huy trưởng (Admin)
- Đội trưởng (Editor)
- Chủ đầu tư (Viewer)
